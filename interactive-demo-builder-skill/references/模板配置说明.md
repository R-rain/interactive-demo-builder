# 模板配置说明

## Copy Rule

Copy the generic HTML file under `assets/宣传交互演示母版/` into the output folder before editing. Do not copy branding or media from another project into the Skill.

## Content Data

The HTML has two key data arrays:

- `scenes`: top-level overview scenes.
- `units`: playback units. Each unit has `name`, `summary`, `intro`, and `features`.

Each feature supports:

```js
{
  id: 'feature-id',
  name: '功能名称',
  seconds: 12,
  benefit: '价值型旁白',
  video: '素材/视频/功能名称.mp4'
}
```

Omit the `video` field until the file is available. The template then shows a placeholder and advances using `seconds` in automatic playback.

## Branding

Update the CSS variables near the beginning of the HTML:

```css
:root {
  --brand: #067fc3;
  --accent: #f05b52;
  --mint: #10b99b;
}
```

The template uses a CSS-only placeholder mark. When the user provides a logo, place it under `素材/logo/` in the output folder and replace the placeholder markup with that logo. Do not store user logos in the Skill assets.

## Theme

在 HTML 配置区设置主题：

```js
const theme = 'saas-indigo';
```

可用主题：`original-template`（母版原风格）、`saas-indigo`（专业蓝域）、`swiss-signal`（瑞士信号）、`aurora-tech`（极光科技）、`editorial-warm`（暖色杂志）、`deep-ops`（深海运营）、`cloud-minimal`（极简云白）、`blueprint`（工业蓝图）。

主题通过 CSS 自定义属性控制颜色、字体、圆角、阴影、背景、标题和卡片风格，不改变页面结构、业务数据或自动播放逻辑。品牌规范优先；信息不足时使用 `original-template`，企业管理场景优先使用 `saas-indigo`。未知值会回退到母版原风格。切换主题后，应检查 Logo 对比度、视频链接、自动播放时长和键盘序列。

## Timing Check

Calculate the automatic-play duration as:

```text
overview duration + all scene intro durations + all feature seconds
```

For a video-bound feature, its final duration follows the actual video duration, so flag any difference from the planned timing in the configuration table.
